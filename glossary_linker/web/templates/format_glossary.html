Formatta Glossario .tex

Prepara un glossario LaTeX con ID stabili e voci confermate. Il file sorgente viene sovrascritto solo se lo scegli nella fase finale.

Torna alla home Impostazioni
Input Carica un file oppure incolla il sorgente LaTeX.
Rilevamento Scegli la struttura usata per riconoscere le voci reali.
Conferma Escludi falsi positivi, correggi definizioni e salva.
