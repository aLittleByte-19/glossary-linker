Sorgenti

La root progetto serve per mostrare path relativi e per scansionare i documenti. Il glossario puo essere un path locale o un URL.

Regole di esclusione

Queste regole dicono al linker dove non deve intervenire. Sono conservative: meglio saltare un caso dubbio che inserire un link nel posto sbagliato.
